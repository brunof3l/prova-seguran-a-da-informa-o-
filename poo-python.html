Módulo 1

Estruturas de Dados: O Essencial

O primeiro módulo cobre listas, dicionários e estruturas aninhadas, pontos que costumam aparecer antes da POO em Python.

📋

Listas e Índices

Listas são sequências ordenadas e indexadas a partir de 0. O primeiro item fica em lista[0] e o último pode ser acessado com lista[-1].

➕

.append() e .insert()

.append() adiciona no fim da lista. .insert() adiciona em uma posição específica, como lista.insert(1, "x").

➖

.remove() e .pop()

.remove() remove por valor. .pop() remove por índice e pode devolver o item removido.

✂️

Fatiamento

O slice permite extrair partes da lista, como em lista[0:2], que pega os elementos do índice 0 até antes do índice 2.

Dicionários em Python

Dicionários funcionam com pares chave-valor, permitindo acessar dados por nome lógico em vez de posição numérica.

.keys() retorna as chaves, .values() retorna os valores e .items() retorna pares de chave e valor, muito úteis em laços for.

Exemplos rápidos com listas e dicionários

lista = ["a", "b", "c"]
lista.append("d")
lista.insert(1, "x")
lista.remove("b")
ultimo = lista.pop(-1)
trecho = lista[0:2]
dicionario = {"nome": "Ana", "idade": 20}
chaves = dicionario.keys()
valores = dicionario.values()
pares = dicionario.items()

for chave, valor in dicionario.items():
    print(chave, valor)

Estruturas Aninhadas

Estruturas aninhadas aparecem quando combinamos listas e dicionários em camadas. Para acessar um dicionário dentro de outro, usamos algo como empresa["endereco"]["cidade"].

Quando há dicionários dentro de listas, o acesso pode ser feito como em produtos[0]["nome"], primeiro escolhendo a posição na lista e depois a chave no dicionário.

Visão do Professor: Como isso cai na prova? +

Pergunta: Como acessar o último item de uma lista?

Resposta: Usando índice negativo lista[-1].

Pergunta: Como iterar sobre chaves e valores de um dicionário?

Resposta: Usando for c, k in dicionario.items():.

Módulo 2

Introdução à POO: Classes e Objetos

Este módulo apresenta a transição da lógica procedural para a POO e organiza os elementos básicos da modelagem orientada a objetos.

P

Programação Procedural

Foco em funções e etapas de execução.

  • Dados e funções costumam ficar separados.
  • Modelo clássico de linguagens como C.
  • Prioriza o o que fazer.
O

POO

Foco em objetos e responsabilidades.

  • Dados e funções ficam juntos nos objetos.
  • Ideal para projetos mais complexos.
  • Prioriza o quem faz o quê.
📐

Classe

É o molde, como a planta de uma casa. Define a estrutura e os comportamentos possíveis de um objeto.

🏠

Objeto

É a instância construída a partir da classe. Se a classe é o projeto, o objeto é a construção pronta.

🧾

Atributos

São variáveis e dados do objeto, como cor, modelo, nome e idade.

▶️

Métodos

São funções e comportamentos do objeto, como ligar(), acelerar() ou apresentar().

Exemplo de leitura conceitual

Em POO, uma classe Carro pode ter atributos como cor e modelo, além de métodos como ligar() e acelerar(). Isso reúne dados e ações no mesmo elemento lógico.

Exemplo em Python

class Carro:
    def __init__(self, cor, modelo):
        self.cor = cor
        self.modelo = modelo

    def ligar(self):
        return "Carro ligado"
meu_carro = Carro("azul", "sedan")
print(meu_carro.cor)
print(meu_carro.ligar())

# cor e modelo -> atributos
# ligar -> método
Visão do Professor: Como isso cai na prova? +

Pergunta: Qual a principal diferença entre Procedural e POO?

Resposta: Procedural foca no "o que fazer" com funções, POO foca em "quem faz o quê" agrupando dados e ações em objetos.

Módulo 3

Pilares Avançados

Este módulo resume os pilares mais avançados da POO, com foco no reaproveitamento de código e na proteção de dados.

🌿

Herança

Permite reaproveitar atributos e métodos de uma classe mãe em classes filhas, reduzindo duplicação de código.

🎭

Polimorfismo

Permite que métodos com o mesmo nome tenham comportamentos diferentes conforme a classe concreta.

🔐

Encapsulamento

Protege dados internos do objeto. Em Python, usa convenção com _ e __, além de getters e setters.

🧠

Abstração

Define modelos gerais de comportamento por meio de classes abstratas que servem como contrato para subclasses.

É

Herança

Relacionamento é um.

  • CarroElétrico é um Carro.
  • Reaproveita estrutura da superclasse.
  • Cria hierarquia entre tipos.
Tem

Composição

Relacionamento tem um.

  • Carro tem um Motor.
  • Combina objetos para formar comportamentos.
  • Reduz acoplamento hierárquico.

Resumo visual

Herança ajuda no reaproveitamento de código. Polimorfismo permite diferentes implementações com a mesma interface. Encapsulamento protege o estado do objeto. Abstração define contratos e modelos.

Exemplos rápidos

class Animal:
    def emitir_som(self):
        return "Som genérico"

class Gato(Animal):
    def emitir_som(self):
        return "Miau"
class Conta:
    def __init__(self, saldo):
        self.__saldo = saldo

    def get_saldo(self):
        return self.__saldo
Visão do Professor: Como isso cai na prova? +

Pergunta: Python possui encapsulamento real como Java?

Resposta: Não, usa convenção de nomenclatura, onde um underscore indica protegido e dois underscores ativam o Name Mangling para simular privacidade.

Pergunta: Qual a importância de getters e setters?

Resposta: Permitem controlar o acesso e a alteração dos atributos, aplicando validação e protegendo a integridade do objeto.

Pergunta: O que é abstração?

Resposta: É o princípio que define um modelo geral de comportamento, normalmente por classes abstratas que não devem ser instanciadas diretamente.
