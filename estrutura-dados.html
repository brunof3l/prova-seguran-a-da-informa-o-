Módulo 1

O Domínio do JSON

O foco aqui é distinguir leitura de string e leitura de ficheiro, além de visualizar como um CRUD básico opera com JSON em Python.

"{ }"

`json.loads()`

Converte uma string JSON em estrutura Python, como `dict` ou `list`.

📄

`json.load()`

Lê JSON a partir de um ficheiro já aberto e converte para estruturas Python.

↔

Fluxo Mental

Se a origem é texto em memória, use `loads()`. Se a origem é disco, use `load()`.

💾

Persistência

JSON é simples para guardar listas e registos pequenos sem depender de base de dados.

Exemplo com `json.loads()`

Recebe uma string e transforma em dicionário.

import json

conteudo = '{"nome": "Ana", "idade": 22}'
dados = json.loads(conteudo)
print(dados["nome"])

Exemplo com `json.load()`

Lê um ficheiro aberto e converte o conteúdo.

import json

with open("alunos.json", "r", encoding="utf-8") as arquivo:
    dados = json.load(arquivo)
print(dados)

CRUD básico em JSON

O padrão mínimo normalmente envolve: carregar, inserir novo item, alterar um item existente, remover por chave e gravar novamente no ficheiro.

import json

ARQUIVO = "usuarios.json"

def carregar():
    try:
        with open(ARQUIVO, "r", encoding="utf-8") as arquivo:
            return json.load(arquivo)
    except FileNotFoundError:
        return []

def salvar(dados):
    with open(ARQUIVO, "w", encoding="utf-8") as arquivo:
        json.dump(dados, arquivo, ensure_ascii=False, indent=2)

def criar(nome, email):
    dados = carregar()
    dados.append({"nome": nome, "email": email})
    salvar(dados)

def atualizar(email, novo_nome):
    dados = carregar()
    for usuario in dados:
        if usuario["email"] == email:
            usuario["nome"] = novo_nome
    salvar(dados)

def remover(email):
    dados = carregar()
    dados = [usuario for usuario in dados if usuario["email"] != email]
    salvar(dados)
Resumo rápido: `loads()` trabalha com string; `load()` trabalha com ficheiro.
Módulo 2

Listas vs Deques

Este bloco compara as duas estruturas em cenários de pilha e fila, com foco especial em custo de operação.

Lista

  • Boa para acesso por índice e operações no fim.
  • `append()` e `pop()` no final costumam ser eficientes.
  • `pop(0)` exige deslocar elementos e piora a performance.

Deque

  • Estrutura da biblioteca `collections` pensada para duas pontas.
  • Excelente para filas e cenários com remoção no início.
  • `popleft()` opera em O(1).
⬆

Pilha (LIFO)

Last In, First Out: o último a entrar é o primeiro a sair.

Exemplo típico: histórico de desfazer e chamadas de função.
➡

Fila (FIFO)

First In, First Out: o primeiro a entrar é o primeiro a sair.

Exemplo típico: fila de impressão e processamento por ordem.
O(1)

Performance

Em fila real, `deque.popleft()` é superior a `lista.pop(0)` porque não precisa deslocar todo o restante da estrutura.

Por que `deque.popleft()` ganha?

Quando você usa `lista.pop(0)`, todos os elementos restantes precisam ser movidos uma posição para a esquerda. Esse custo cresce com o tamanho da lista.

No `deque`, a remoção na esquerda já foi desenhada para acontecer de forma direta, com custo constante O(1).

from collections import deque

fila = deque(["A", "B", "C"])
primeiro = fila.popleft()  # O(1)

lista = ["A", "B", "C"]
primeiro_lista = lista.pop(0)  # custo maior
Regra prática: se a estrutura precisa remover ou inserir no início com frequência, pense em `deque`.

Módulo 3

Dicionários e Segurança

O objetivo deste módulo é ligar a estrutura chave-valor à escrita de código mais segura e previsível em Python.

K:V

Chave-Valor

Um dicionário associa uma chave a um valor, permitindo acesso rápido por identificador.

{ }

Estrutura

É ideal para registos, configurações e mapeamentos como utilizador, produto ou resposta de API.

⚠

`KeyError`

Acontece quando tentamos acessar uma chave inexistente com `dicionario["chave"]`.

🛡

`.get()`

Permite retornar um valor padrão quando a chave não existe, reduzindo falhas em tempo de execução.

Destaque para `get(chave, padrao)`

Em código real, nem sempre temos garantia de que toda chave virá presente. Por isso, `get()` é uma defesa simples e muito valiosa.

usuario = {"nome": "Lia", "perfil": "admin"}

nome = usuario.get("nome", "Desconhecido")
telefone = usuario.get("telefone", "Não informado")

print(nome)
print(telefone)
Com `usuario["telefone"]`, o código geraria `KeyError`. Com `get()`, você recebe um valor padrão.

Leitura segura de dados

Quando trabalha com JSON, APIs ou formulários, o uso de `get()` ajuda a lidar com campos opcionais sem interromper a execução do programa.

Em revisão de prova, a ideia-chave é: dicionário organiza dados por chave-valor e `get(chave, padrao)` evita acesso inseguro a chaves ausentes.
